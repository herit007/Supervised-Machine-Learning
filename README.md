# 🤖 Supervised Machine Learning

A collection of practical **supervised machine learning projects** covering classification, regression, model evaluation, ensemble learning, preprocessing, and real-world prediction problems.

This repository brings together my hands-on work while learning and applying machine learning concepts with Python and Scikit-learn.

## 🚀 Projects

### 📩 Message Intelligence System
**Classification — Spam vs Legitimate Messages**

A multi-model classification project comparing **KNN, SVM, and Naive Bayes**. It also covers probability concepts, feature preprocessing, model tuning, and evaluation using Precision, Recall, F1 Score, and other metrics.

👉 [View Project](./Message_Intelligence_System)

---

### 🚨 Risk Alert Classifier
**Classification — High Risk vs Low Risk Customers**

A financial risk prediction project covering **KNN Imputation, EDA, feature preprocessing, class imbalance handling, model building, hyperparameter tuning, and evaluation**.

Models include:
- Logistic Regression
- Decision Tree
- Random Forest

Imbalance techniques include:
- Random Over Sampling
- Random Under Sampling
- SMOTE
- ADASYN

👉 [View Project](./Risk_Alert_Classifier)

---

### 📊 Customer Churn Prediction
**Classification — Customer Churn Prediction**

A Logistic Regression project that predicts whether a customer is likely to churn based on demographic, subscription, spending, and service-interaction information.

The project covers EDA, preprocessing, encoding, scaling, feature selection, and classification evaluation.

👉 [View Project](./Customer%20Churn%20Prediction)

---

### 🏠 House Price Prediction
**Regression — House Price Prediction**

A regression project comparing multiple models for predicting house prices from property characteristics.

Models include:
- Ridge Regression
- Lasso Regression
- Decision Tree Regression
- Random Forest Regression
- Support Vector Regression

The project also explores cross-validation and metrics such as **MAE, MSE, RMSE, and R²**.

🏆 Random Forest Regression achieved the best recorded performance with an **R² score of 0.93** on the project test evaluation.

👉 [View Project](./Projects/House_Price_Prediction)

---

### 🧠 Smart Outcome Predictor
**Ensemble Learning — Student Outcome Prediction**

An ensemble-based project with two prediction tasks:

- **Classification:** Predict whether a student will complete an online course.
- **Regression:** Predict the student's final score.

Methods explored include:
- Bagging
- AdaBoost
- Gradient Boosting
- LightGBM
- XGBoost
- Hard & Soft Voting
- Stacking

🏆 Best recorded models:
- **XGBoost Classifier** — F1 Score: 0.6173
- **Gradient Boosting Regressor** — RMSE: 9.7958, R²: 0.4864

👉 [View Project](./Smart_Outcome_Predictor)
